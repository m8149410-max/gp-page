# МойСайт

Простой одностраничный шаблон сайта с аккуратными hover-эффектами. Минималистичный дизайн, быстрая загрузка и адаптивная вёрстка.

🔗 **Демо:** [odiysayt2.netlify.app](https://odiysayt2.netlify.app/)

## Возможности

- **Минималистичный дизайн** — чистый и понятный внешний вид
- **Скорость** — быстрая загрузка без лишнего кода
- **Адаптивность** — корректно отображается на телефонах, планшетах и компьютерах
- **Hover-эффекты** — плавные анимации при наведении

## Структура страницы

| Раздел   | Описание                               |
|----------|----------------------------------------|
| Главная  | Приветствие и кнопка «Узнать больше»   |
| О нас    | Информация о проекте                   |
| Услуги   | Список услуг                           |
| Контакты | Контактная информация                  |

## Запуск локально

1. Склонируйте репозиторий:

   ```bash
   git clone https://github.com/<ваш-логин>/<название-репозитория>.git
   ```

2. Перейдите в папку проекта:

   ```bash
   cd <название-репозитория>
   ```

3. Откройте `index.html` в браузере. Для удобства можно использовать расширение Live Server в VS Code.

## Деплой

Сайт опубликован на [Netlify](https://www.netlify.com/). Чтобы развернуть свою копию:

1. Залейте проект в GitHub.
2. На Netlify выберите **Add new site → Import an existing project**.
3. Подключите репозиторий и нажмите **Deploy**. Сборка не требуется, достаточно указать корневую папку.

Также можно просто перетащить папку проекта на страницу [Netlify Drop](https://app.netlify.com/drop).

## Настройка

- Название сайта и тексты меняются в `index.html`.
- Цвета, шрифты и hover-эффекты настраиваются в CSS.
